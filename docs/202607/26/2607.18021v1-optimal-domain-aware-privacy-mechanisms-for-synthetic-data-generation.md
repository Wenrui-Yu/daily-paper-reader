## 摘要
差分隐私在合成数据生成中强制了隐私与统计保真度之间的基本权衡。虽然已有实证表明访问公共数据可以改善这些权衡，但现有方法仅通过预处理（例如，使用预训练生成模型）或后处理步骤（例如，匹配从公共数据集估计的目标统计量）间接使用公共数据，同时依赖领域无关的差分隐私机制。在这项工作中，我们建立了理论框架来研究将公共数据原则性地融入差分隐私机制本身。我们将归一化直方图作为分布估计器，并在一类特定的差分隐私机制中刻画了渐近最优的领域感知隐私机制。我们提出了PubMix，一种可在基于直方图的数据合成流程中使用的公共数据感知差分隐私机制。我们的实验表明，与领域无关的隐私机制相比，PubMix显著提升了合成数据生成的質量。

## Abstract
Differential privacy (DP) imposes fundamental trade-offs between privacy and statistical fidelity in synthetic data generation. While access to public data has been shown to improve these trade-offs empirically, existing approaches use public data only indirectly, through pre-processing (e.g., using pre-trained generative models) or post-processing steps (e.g., matching target statistics estimated from public datasets), while relying on domain-agnostic DP mechanisms. In this work, we lay the theoretical framework to study the principled incorporation of public data into DP mechanisms themselves. We consider normalized histograms as distribution estimators and characterize the asymptotically optimal domain-aware privacy mechanism within a specific class of DP mechanisms. We introduce PubMix, a public-data-aware DP mechanism that can be used in histogram-based data synthesis pipelines. Our experiments demonstrate that PubMix significantly improves synthetic data generation quality compared to domain-agnostic privacy mechanisms.

- **核心问题**：在差分隐私（DP）合成数据生成中，存在一个根本性的权衡：如何在不泄露个体隐私的前提下，生成统计上高保真度的合成数据。传统的DP机制（如添加拉普拉斯或高斯噪声）是**领域无关**的，它们以相同的方式扰动所有数据方向。这导致合成数据的效用，尤其是在高维或稀疏数据上，会急剧下降。

### 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：利用公共数据构建**领域感知的噪声分布**，并将其与私有分布的估计（归一化直方图）进行**线性混合**，生成最终用于采样的合成数据分布。
- **关键技术细节**：
    1.  **问题形式化**：将合成数据分布定义为 `Psyn = (1 - β) * Pprv_hist + β * Pnse`。
        - `Pprv_hist`：私有数据的归一化直方图。
        - `Pnse`：一个需要优化的噪声分布（这是关键优化变量）。
        - `β`：混合系数。
    2.  **优化目标**：寻找最优的 `(β, Pnse)`，以最小化合成分布 `Psyn` 与私有分布 `Pprv_hist` 之间的总变差距离（Total Variation, TV），同时满足 (ε, δ)-DP 约束。
    3.  **约束条件**：
        - **隐私约束**：通过分析相邻数据集的差异，论文将DP约束转化为一个关于β` 和 `Pnse` 的数学条件，最终发现DP约束**只依赖于噪声分布 `Pnse` 的两个最小概率质量 (`Nmin1, Nmin2`)**。这简化了问题的复杂性。
        - **效用约束（优化域）**：假设私有分布很可能接近公共分布 `Ppub_hist`，因此将搜索空间限制在以公共分布为中心、半径为`γ` 的 TV 球 `Bγ, Ppub` 内。
    4.  **渐近最优解 (`PubMix`)**：
        - 通过理论分析，论文证明对于高维数据（d 很大），最优解近似为：将混合系数 `β` 设定为满足DP的最小值，而最优噪声分布 `Pnse*` 是**公共分布 `Ppub_hist` 的一个“抬底”（floor-raised）版本**。
        - **“抬底”（Floor-Raising）操作**：将公共分布中所有概率质量低于某个阈值 `t` 的项（通常是稀疏/零值）提高到 `t` 以上。这保证了即使在稀疏区域也有足够的随机性来掩码个体隐私，同时保留了主体结构。论文引入了两种具体实现：`Water-Filling (WF)` 和 `Maximum-Invariance Floor Raising (MIFR)`。
- **算法流程（文字说明）**：
    1.  **离线计算**：基于公共分布 `Ppub_hist`、邻近性参数 `γ`、隐私预算 `(ε, δ)` 和合成样本数 `m`，通过求解一个优化问题，预计算出最优的抬底阈值 `t*`，进而得到最优噪声分布 `Pnse*` 和最优混合系数 `β*`。
    2.  **线上应用**：对于给定的私有数据直方图 `Pprv_hist`，直接计算 `Psyn = (1 - β*) * Pprv_hist + β* * Pnse*`。
    3.  **采样**：从 `Psyn` 中进行 `m` 次独立同分布采样，得到最终的合成数据集 `Dsyn`。

### 6. 主要结论与发现

- **领域感知加噪效果显著**：将公共数据直接融入DP噪声机制设计，可以大幅提升隐私-效用权衡。`PubMix` 在几乎所有设置下都优于领域无关的基线（如高斯机制、`LinMix`）和现有的利用公共数据的方法。
- **“抬底”操作是核心**：最优噪声分布不是原始的公共分布，而是其“抬底”版本。这平衡了两个目标：**① 靠近公共分布**（以最小化与私有分布的TV距离）和**② 提高最小概率质量**（以允许更小的混合系数β，从而更多地保留私有分布信息）。

### 8. 不足与局限

- **理论适用性限制**：理论分析严格局限于**线性混合**这一机制类以及**归一化直方图**作为分布估计器。对于更复杂的生成模型（如VAEs, GANs, Diffusion Models）和更高级的隐私机制，其理论框架不能直接应用。
- **数据依赖性**：该方法严重依赖**来自同一领域的、有代表性的公共数据**。如果公共数据和私有数据之间存在较大的分布偏移（即`γ`估计不准），那么`PubMix`虽然会满足隐私，但其效用可能会不如领域无关方法。
- **实验验证的不足**：

    - **隐私参数设置**：论文主要在相对宽松的隐私预算下（ε >= 1）进行实验。在极强隐私（如 ε << 1）下的性能未知。
- **潜在偏差风险**：论文没有讨论`PubMix`在放大或引入公共数据中的社会偏见的可能性。如果公共数据本身就包含偏见，那么去噪后的“抬底”操作可能会固化甚至加剧这些偏见，这也符合论文影响陈述中提到的局限。
