## 摘要
联邦学习使多个机构能够在无需交换原始临床脑电数据的情况下训练共享模型，但它并不能完全防止个体模型更新导致的隐私泄露。本文提出了一种针对临床脑电数据的隐私保护联邦学习框架，以基于掩码的安全聚合作为核心保护机制。该框架结合了基于图的通信、门限秘密共享、抗丢弃聚合、局部更新裁剪、可选的基于布隆过滤器的隐私保护记录链接初始化模块，以及基于辅助公证人的可验证性。它支持半诚实和恶意聚合设置，并使用Flower联邦学习框架实现。在模拟的跨机构医疗环境中，使用TUH脑电数据衍生的数据集，在不同客户端配置下对安全聚合变体进行了评估。在所述假设下，安全变体对聚合服务器隐藏了个体更新。结果表明，这些变体与联邦模型训练保持兼容，尽管恶意设置的安全保障和轻量级一致性检查机制引入了额外的计算、通信和轮次持续时间开销。在半诚实设置的安全配置中，半诚实变体提供了最低的开销，而恶意和辅助公证人变体则以更高的成本提供了更强的一致性、完整性和轻量级验证支持。

## Abstract
Federated learning enables multiple institutions to train shared models without exchanging raw clinical EEG data, but it does not fully prevent privacy leakage from individual model updates. This paper presents a privacy-preserving federated learning framework for clinical EEG data using masking-based secure aggregation as the core protection mechanism. The framework combines graph-based communication, threshold secret sharing, dropout-resilient aggregation, local update clipping, an optional Bloom filter-based privacy-preserving record-linkage initialization module, and auxiliary-notary-based verifiability. It supports both semi-honest and malicious aggregation settings and is implemented using the Flower federated learning framework. The secure-aggregation variants are evaluated in a simulated cross-silo healthcare setting using TUH EEG-derived data under different client configurations. Under the stated assumptions, the secure variants hide individual updates from the aggregation server. The results show that these variants remain compatible with federated model training, although malicious-setting safeguards and lightweight consistency-checking mechanisms introduce additional computation, communication, and round-duration overhead. The semi-honest variant provides the lowest overhead among the secure configurations, while malicious and auxiliary-notary variants offer stronger consistency, integrity, and lightweight verification support at higher cost.

## 1. 论文的核心问题与整体含义

- **研究动机**：联邦学习（FL）允许医疗机构在不共享原始临床脑电（EEG）数据的前提下协作训练模型，但仅靠 FL 本身无法完全保护隐私——攻击者可能从个体模型更新中重建或推断敏感信息。临床 EEG 数据涉及患者隐私，且存在跨机构非独立同分布、通信成本高、参与者掉线等挑战，因此需要在实际 FL 流程中集成更强的隐私保护机制。
- **核心问题**：如何在不暴露个体更新的前提下，实现支持掉线恢复、通信开销可控、可抵御半诚实乃至恶意服务器的安全聚合框架，并使其适用于临床 EEG 数据的跨机构联邦学习场景。
- **整体含义**：论文提出了一个基于掩码安全聚合的完整框架，将隐私保护从“仅隐藏原始数据”提升到“隐藏个体模型更新”的层面，并以实际 EEG 数据验证了其与联邦训练流程的兼容性，为医疗 FL 中的隐私-开销权衡提供了可操作的方案。

## 2. 论文提出的方法论

- **核心思想**：采用掩码（masking）安全聚合，使服务器只能恢复客户端更新的聚合值，而无法获取任何个体明文更新。方法综合了多种机制：
  - **基于图的通信**：每个客户端仅与固定数量的邻居通信，避免稠密全对全掩码的高通信开销。
  - **阈值秘密共享**（Shamir 门限）：将自掩码种子和掩码私钥分片分发给邻居，支持掉线恢复。
  - **局部更新裁剪**：对更新做 ℓ2 范数裁剪（阈值 τ），避免异常大更新带来的隐私或数值风险。
  - **量化与模运算**：将实数更新量化到整数域，在模 M = 2³² 下完成掩码与聚合，防止模回绕。
  - **可选布隆过滤器记录链接**：训练前用 HMAC+布隆过滤器对患者标识进行隐私保护匹配，避免明文标识交换。
- **四种协议变体**：
  - **Π1（半诚实）**：基础掩码安全聚合 + 图通信 + 秘密共享 + 掉线恢复。
  - **Π2（恶意）**：在 Π1 基础上增加 Merkle 公钥承诺、签名、确认证据、一致性检查，限制服务器视图不一致、伪造参与或非法释放恢复份额。
  - **Π3（半诚实 + 辅助公证人 AN）**：增加辅助公证人，基于线性验证标签（内积）对聚合结果进行轻量级一致性检查。
  - **Π4（恶意 + AN）**：Π2 与 AN 验证机制结合。
- **关键技术细节**：
  - 掩码构造：`y_i = z_i + F(b_i) - Σ_{j<i} a_{i,j} + Σ_{j>i} a_{i,j} (mod M)`，成对掩码在聚合中抵消，自掩码通过秘密共享恢复。
  - AN 验证：利用公开随机种子 `ρ_r` 生成验证向量 `u^{(r,ν)}`，客户端计算 `tag_i = ⟨u, z_i⟩ mod q`，服务器输出聚合 `Y_Q` 后，客户端检查 `⟨u, Y_Q⟩ ≡ Σ tag_i (mod q)`。
  - 掉线处理：通过邻居共享重建自掩码种子或丢弃客户端的掩码私钥，从而移除残留掩码。
  - 协议流程以多阶段集合 `[n] ⊇ A1 ⊇ A'1 ⊇ A2 ⊇ A'2 ...` 跟踪客户端活跃状态，在恶意设置中增加签名与确认门限 p。

## 3. 实验设计

- **数据集**：TUH EEG Corpus 衍生子集，共 2,500 个 EDF 文件（1,250 正常 + 1,250 异常），约 50 GB。预处理后重采样至 100 Hz、19 通道、10 秒窗口、按通道归一化。
- **模型与训练**：1D CNN（3 个卷积层，60,034 参数），交叉熵损失，Adam 优化器（lr=0.0005），batch size 16，本地 2 个 epoch，100 轮 FL 通信。
- **客户端配置**：
  - 10 客户端：每客户端 250 个文件，5 次运行。
  - 40 客户端：从 70 个文件夹中每轮选 40 个活跃客户端，每客户端 30 个文件，5 次运行。
  - 70 客户端：从 140 个文件夹中选 70 个活跃客户端，每客户端 18 个文件，1 次运行。
- **对比方法**：
  - **Baseline FL**：标准 FedAvg，无安全聚合。
  - **Basic SecAgg**：Bonawitz 等人的经典掩码安全聚合协议。
  - **Π1–Π4**：论文提出的四种变体。
- **评价指标**：聚合时间、服务器端/客户端协议计算时间、训练与评估时间、轮时间、通信量（协议流量字节数）、分布式评估准确率。
- **实验场景**：未注入主动掉线、服务器欺骗或恶意客户端行为；记录链接模块因数据无可用链接属性而未参与实验。

## 5. 实验数量与充分性

- **实验组数**：共 6 种协议（Baseline、SecAgg、Π1、Π2、Π3、Π4）× 3 种客户端配置（10/40/70），其中 10 和 40 客户端重复 5 次，70 客户端 1 次。
- **充分性评价**：
  - 优点：覆盖了不同规模（10、40、70）和不同安全级别（半诚实、恶意、可验证）的对比，能反映协议开销随客户端规模的变化趋势。

## 6. 论文的主要结论与发现

- 在半诚实和恶意设置下，所提出的安全聚合变体均能实现“隐藏个体更新”的目标，且与联邦训练流程兼容。
- 半诚实变体（Π1）在安全配置中开销最低；恶意变体（Π2）因承诺、签名、一致性检查等机制显著增加计算与通信开销；AN 变体（Π3/Π4）额外引入验证标签与公证人通信，开销更高。
- 安全性越强，开销越大，但框架提供了可调的保护等级（半诚实 → 恶意 → 加可验证性）。
- 准确率随客户端数量增加而下降，主要原因是每个客户端本地数据减少，但论文强调这并非优化后的 EEG 分类基准，只说明隐私保护变体不影响基本学习能力。
- 服务器端计算量随客户端数量增加而增加；AN 机制仅验证一致性，不改变接受更新，因此 AN 与无 AN 的准确率差异不应归因于 AN 本身。

## 7. 优点

- **实践性强**：基于 Flower 框架实现了完整可运行的联邦学习系统，而非仅停留在协议层面。
- **综合安全设计**：同时考虑半诚实与恶意服务器，并引入辅助公证人，提供多等级隐私-安全性选择。
- **通信优化**：用稀疏图通信替代稠密掩码，显著降低客户端间通信开销，适合跨机构医疗场景。
- **实用组件**：包括更新裁剪、量化、掉线恢复、可选的记录链接模块，贴近真实医疗数据需求。

## 8. 不足与局限

- **实验统计不足**：70 客户端单次运行、10/40 客户端无方差报告，结果仅为趋势性参考。

- **缺少攻击模拟**：未注入主动掉线、服务器恶意行为、客户端中毒或拜占庭行为，因此“恶意设置”的安全增强没有在对抗性实验中验证。

- **精度与隐私的数值风险**：论文只声称“在报告的客户端配置下”避免模回绕，未给出一般性保障或最坏情况分析。
