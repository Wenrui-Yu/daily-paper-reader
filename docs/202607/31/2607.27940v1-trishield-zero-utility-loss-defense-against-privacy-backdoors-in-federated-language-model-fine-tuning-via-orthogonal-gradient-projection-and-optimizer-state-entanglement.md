## 摘要
联邦微调大型语言模型（LLM）能够在无需暴露原始数据的情况下实现协作训练。然而，近期一种名为NeuroImprint的攻击（arXiv:2606.20553）表明，恶意参数服务器可以将PEFT适配器污染为隐私后门：通过为每个训练样本分配专用记忆神经元，并确保每个神经元最多更新一次，服务器可以分析性地重建客户端训练数据的59%至79%，且具有较高的语义保真度。现有防御措施——包括本地差分隐私（LDP）和梯度裁剪——要么无法抵御此类攻击，要么导致不可接受的效用下降。我们提出了TriShield，一种三层确定性防御方法，能够完全阻止NeuroImprint式重构，且不造成任何模型效用损失，也不增加额外通信轮次。TriShield包括：（1）**参数伪影检测器**，在本地训练开始前识别分布式模型参数中的记忆神经元特征；（2）**有状态虚拟迭代机制**，强制Adam/AdamW的动量状态在虚拟步之间不可逆地纠缠梯度，使NeuroImprint的闭式反演失效；（3）**零效用正交投影算子**，将所有本地梯度更新投影到通过SVD计算的主任务语义子空间上，从物理上消除任何携带私有记忆的梯度分量。我们从理论上证明，经过第二层和第三层处理后，上传梯度与任何单个训练样本之间的互信息为零。在GPT-2（117M）和Llama-Guard-3-1B上的实验验证，TriShield在所有测试的攻击变体中将NeuroImprint重构率降至0，同时保持或提升训练准确率，且额外GPU计算开销低于5%。

## Abstract
Federated fine-tuning of large language models (LLMs) enables collaborative training without exposing raw data. However, a recent attack, NeuroImprint [1] (arXiv:2606.20553), demonstrates that a malicious parameter server can corrupt a PEFT adapter into a privacy backdoor: by assigning a dedicated memorization neuron to each training sample and ensuring each neuron updates at most once, the server can analytically reconstruct 59\%--79\% of client training data with high semantic fidelity. Existing defenses---including local differential privacy (LDP) [8] and gradient clipping---either fail against this attack or impose unacceptable utility degradation. We present \textbf{TriShield}, a three-layer deterministic defense that completely prevents NeuroImprint-style reconstruction with \textbf{zero model utility loss} and \textbf{no additional communication rounds}. TriShield consists of: (1) a \textbf{Parameter Artifact Detector} that identifies memory-neuron signatures in distributed model parameters before local training begins; (2) a \textbf{Stateful Virtual Iteration} mechanism that forces Adam/AdamW's momentum state to irreversibly entangle gradients across virtual steps, invalidating NeuroImprint's closed-form inversion; and (3) a \textbf{Zero-Utility Orthogonal Projection} operator that projects all local gradient updates onto the main-task semantic subspace computed via SVD, physically eliminating any gradient components that carry private memorization. We prove theoretically that after Layers 2 and 3, the mutual information between the uploaded gradient and any individual training sample is zero. Experiments on GPT-2 (117M) and Llama-Guard-3-1B verify that TriShield reduces NeuroImprint reconstruction rate to \textbf{0\%} across all tested attack variants, while maintaining or improving training accuracy, with less than 5\% additional GPU computation overhead.

## 二、方法论：TriShield 三层防御框架

TriShield 是三层客户端侧确定性防御流水线，在本地训练前、训练中和上传前分别对攻击的不同环节进行破坏：

### Layer 1：参数伪影检测器（PAD, Parameter Artifact Detector）

- **目标**：在本地训练开始前，检测服务器下发的适配器中是否存在记忆神经元签名。
- **检测依据**：
  - **行内方差异常**：记忆行的行内方差趋近于零（≈10⁻¹²），远低于正常 Kaiming 初始化的行内方差（≈10⁻³）；
  - **行间高相关**：多行归一化向量相关性 > 0.95；
  - **偏置异常**：对应偏置接近固定常数 β。
- **处理方式**：将检测到的记忆神经元重置为 Kaiming 正态初始化，从源头破坏"槽—样本"映射关系，且不涉及任务梯度，零效用损失。

### Layer 2：有状态虚拟迭代（SVI, Stateful Virtual Iteration）

- **目标**：破坏 NeuroImprint 依赖的"单步激活、无线动量混合"假设。
- **核心原理**：在正式训练前，用公开辅助数据 D_aux 在冻结的适配器上执行 K 次虚拟前向-反向传播，**只更新 Adam 动量状态（m, v），不回传参数更新**。
- **攻击失效机制**：预置动量状态后，记忆神经元接收真实梯度 g_real 时，最终更新变为非线性混合函数 `Δθ = f(m_K, v_K, g_real)`。服务器无法在未知 m_K, v_K 的情况下分离出 g_real，闭式反演失效（Theorem 1，欠定方程系统）。

### Layer 3：零效用正交投影（ZUOP, Zero-Utility Orthogonal Projection）

- **目标**：提供最终的信息论级保障——哪怕前两层被针对性的变体绕过，ZUOP 从梯度信号本身物理移除私有记忆分量。
- **核心洞察**：NeuroImprint 的记忆神经元梯度**位于任务梯度的正交补空间**中（为保持 LayerNorm 不变量，记忆神经元的编码方向与主任务损失方向正交）。
- **算法流程**：
  1. 在公开辅助数据 D_aux 上计算任务梯度矩阵 G；
  2. 对 G 做 SVD 分解，取前 k 个左奇异向量构成主任务子空间 U_k；
  3. 将上传梯度投影到 U_k 上：`Δφ* = U_k U_kᵀ · Δφ`，从而消除正交子空间中的隐私分量。
- **关键参数**：投影秩 `k = min(0.8 × rank(G), n−1)`（秩分数 = 0.80 是经过验证的安全默认值；0.95 会导致 SR1E 变体泄漏 12–50%）。

### 理论保证

- **Theorem 2（零效用损失）**：若任务梯度位于主任务子空间内，则投影后任务梯度保持精确不变。
- **Theorem 3（隐私保证）**：记忆神经元梯度位于任务子空间正交补中，投影后严格为零。
- **Corollary 1（重建不可能性）**：攻击者的重建公式变为 0/0（未定义），互信息 I(x̂; x) = 0。
- **Theorem 4（信息安全界）**：对近似正交（δ < 5°）的扰动，泄漏信息 < 0.008·H(x_j)。
- **Theorem 5（收敛性）**：满足条件时，TriShield 与标准 FedAvg 收敛到相同不动点。

## 六、主要结论与发现

1. **端到端防御有效**：TriShield 三层联合作用下，NeuroImprint 在所有测试变体（VTB/MLD/MLPL/LCN/SR1E）上的 token 重建率均降至 **0%**（与无攻击噪声底线一致）。

3. **三层分工明确**：
   - PAD 在**训练前**以 n 无关的方式重置记忆神经元（100% 检测率）；
   - SVI 破坏闭式反演所需的线性条件（梯度范数不变，但方向不可解码）；
   - ZUOP 是唯一直接降低梯度范数（4.13×10⁻² → 3.08×10⁻³，约 13 倍）的层，物理移除正交隐私分量。
4. **关键参数敏感性**：投影秩分数是成败关键——0.80 安全，0.95 会导致 SR1E 泄漏 50%（本地实测），必须保守设置。
5. **开销可控**：GPU 下额外开销 < 5%（论文宣称 < 4–8%）。

## 七、优点与亮点

1. **问题切入精准**：针对"恶意服务器 + PEFT 隐私后门"这一新兴且高威胁的场景，填补了现有防御（均为服务器侧）的空白，定位清晰。
2. **三层纵深防御设计**：三层各阻断攻击链条的不同环节（参数注入 → 优化器线性假设 → 梯度信号本身），即使某层被针对性绕过，其余层仍独立提供保护，鲁棒性强。
3. **可证明的安全性**：从互信息角度给出了严格的信息论级隐私保证（I(x̂; x) = 0），这一点优于 LDP 的近似保证和启发式防御。
4. **零效用损失的巧妙设计**：利用攻击自身的正交性（LayerNorm 不变量的副产品）反向操作——"用任务子空间做筛子，滤掉一切不在筛内的东西"——概念优雅。
5. **工程实践友好**：纯客户端侧修改，无需服务器配合，协议透明，约 100 行代码即可集成到现有 FL 框架。
6. **自适应攻击分析透彻**：系统地构造了 5 个逃避变体并逐一验证防御有效性，展示了对攻击者可能策略的深入考虑。

1. **大规模实验缺失**：全规模结果全部为**投影估算**而非实测；Llama-Guard-3-1B 的大规模微调被作者明确标注为"未来工作"，结论强度打折。
2. **端到端验证规模过小**：本地实测仅 15 个训练样本，统计功效有限；单样本变化即造成 6.67% 准确率波动，训练效用的结论缺乏足够的统计证据支撑。
3. **辅助数据集依赖**：ZUOP 需要 32–500 条与私有数据同分布的无偏公开数据；在无公开语料的极端专业领域（如医学基因组学）可能难以满足，若辅助数据分布偏移，投影可能损害效用。
4. **参数敏感性**：投影秩分数对安全防御有决定性影响（0.95 即泄漏 50%），但实际部署时客户端难以自行验证子空间维度与任务梯度的匹配度，参数调优需要经验指导。
5. **定理假设的边界**：Theorem 3 依赖"记忆神经元梯度严格正交于任务子空间"的假设；论文自身也承认，跨神经元纠缠编码或非 LoRA 适配器的新攻击可能需要扩展分析。
6. **未处理诚实但好奇的服务器**：TriShield 保护的是样本级重建，但投影后的梯度仍携带分布级统计信息，可能无法防止属性推断或成员推理等更广义的隐私攻击。
7. **CPU 开销显著**：CPU-only 环境中 SVI + ZUOP 开销达到约 72%，移动端/边缘设备部署受限。
