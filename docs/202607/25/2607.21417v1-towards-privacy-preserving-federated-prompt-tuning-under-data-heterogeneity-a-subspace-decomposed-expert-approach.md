## 摘要
联邦提示调优（FPT）通过使用轻量级提示实现视觉-语言模型（VLM）的协同适配。现有方法通常通过本地差分隐私（DP）下的分割提示设计来处理异构性和隐私问题，将共享提示用于全局迁移，私有提示用于本地适配。然而，单一共享提示可能过度平滑多样化的可迁移知识，削弱个性化与泛化之间的平衡。多专家提示（MEP）能更好地捕捉这种多样性，但会扩大通信空间，增加DP噪声和通信成本，同时使稳健的专家组合更加困难。我们提出FedSEPT，一种隐私保护的联邦子空间分解专家提示调优方法。具体地，我们采用子空间分解专家建模（SEM）来参数化多个提示专家，通过共享低秩因子、固定公共基和私有残差，从而将通信和DP扰动限制在紧凑的因子空间内，同时实现在公共坐标系中的直接服务器聚合。我们还设计了实例感知专家融合（IEF），通过设备端路由自适应地组合语义互补的专家，并利用缓存的专家特定文本特征进行高效的对数级融合。在11个异构基准上的大量实验表明，在相同隐私约束下，FedSEPT比强基线实现了本地适配与全局泛化之间更好的权衡。

## Abstract
Federated prompt tuning (FPT) enables collaborative adaptation of vision--language models (VLMs) using lightweight prompts. Existing methods often address heterogeneity and privacy through a split-prompt design under local differential privacy (DP), combining a shared prompt for global transfer with private prompts for local adaptation. However, a single shared prompt may over-smooth diverse transferable knowledge, weakening the balance between personalization and generalization. Multi-expert prompts (MEPs) can better capture this diversity, but enlarge the communicated space, increasing DP noise and communication cost while making robust expert composition more difficult. We propose FedSEPT, a privacy-preserving Fed}erated Subspace-decomposed Expert Prompt Tuning. Specifically, we employ Subspace-decomposed Expert Modeling (SEM) to parameterize multiple prompt experts with shared low-rank factors, a fixed public basis, and private residuals, thereby confining communication and DP perturbation to a compact factor space while enabling direct server aggregation in a common coordinate system. We further design Instance-aware Expert Fusion (IEF), which adaptively combines semantically complementary experts via on-device routing and performs efficient logit-level fusion using cached expert-specific text features. Extensive experiments on 11 heterogeneous benchmarks show that, under the same privacy constraints, FedSEPT achieves a better trade-off between local adaptation and global generalization than strong baselines.

## 1. 核心问题与研究动机

联邦提示调优（FPT）允许多个客户端在冻结的大型视觉-语言模型（VLM）上协同优化轻量级提示（prompts），实现参数高效的分布式适配。然而，实际应用中面临两大挑战：

- **数据异构性**：各客户端数据分布存在显著差异（标签偏移、域偏移等），单一共享提示会过度平滑多样化的可迁移知识，削弱个性化与泛化之间的平衡。
- **隐私保护**：提示更新可能泄露敏感信息，需要本地差分隐私（Local DP）保护，但多专家提示会急剧增加通信开销和DP噪声，导致噪声放大和专家组合困难。

现有方法（如分割提示架构）虽能一定程度缓解异构性，但依赖单一共享提示，无法捕捉多模态迁移知识；多专家提示能提升表达力，却带来“维度灾难”和“鲁棒组合屏障”。因此，核心问题是如何在隐私保护前提下，实现高效、鲁棒的多专家提示协同调优。

## 2. 方法论：FedSEPT 框架

### 核心思想
通过**子空间分解专家建模（SEM）**将多个专家提示参数化为共享低秩因子、固定公共基和私有残差，将通信和DP扰动限制在紧凑因子空间；并通过**实例感知专家融合（IEF）**动态组合专家，在logit层进行高效融合。

### 关键技术细节

- **子空间分解专家建模（SEM）**：每个客户端维护M个专家提示，第m个专家表示为：
  \[
  P_k^m = A_k^m B_0 + R_k
  \]
  其中 \(A_k^m \in \mathbb{R}^{L \times r}\) 为低秩专家因子（仅这部分上传聚合），\(B_0 \in \mathbb{R}^{r \times d}\) 为固定公共基（所有客户端一致），\(R_k\) 为客户端私有残差（不离线）。通过固定公共基保证不同客户端因子在同一坐标系，可直接加权平均。参数从 \(M L d\) 降至 \(M L r\)（\(r \ll d\)）。

- **专家多样性正则化**：防止专家坍缩，通过Gram矩阵的off-diagonal惩罚项 \(\mathcal{L}_{\text{div}}\) 鼓励专家互补。

- **实例感知专家融合（IEF）**：
  - **路由**：客户端使用轻量级路由器（MultiHeadAttn + Linear Gate）根据图像特征预测专家权重 \(\pi_k(x)\)。
  - **logit级融合**：预计算并缓存每个专家-类别的文本特征 \(t_{k,c}^m\)，然后对每个样本加权融合对数几率：
    \[
    z_{k,c}(x) = \sum_{m=1}^M \pi_{k,m}(x) \cdot \langle v(x), t_{k,c}^m \rangle / \tau
    \]
    避免多次文本编码，提升效率。
  - **负载均衡正则化**：\(\mathcal{L}_{\text{gate}}\) 防止路由坍缩。

- **联邦私有优化**：仅对共享因子 \(A_k\) 应用DP-SGD（梯度裁剪+高斯噪声），服务器按专家索引加权聚合。定理4.1给出 \(\epsilon, \delta\) -DP保证。

### 算法流程（文字说明）
1. 服务器初始化全局专家因子 \(A^{(0)}\) 和固定公共基 \(B_0\)。
2. 客户端初始化本地私有参数（残差 \(R_k\)、路由参数等）。
3. 每轮通信：服务器广播全局因子；各客户端并行执行本地训练（多轮），构造专家提示、计算路由权重、logit融合、计算总损失，对共享因子执行DP-SGD更新；上传私有化后的因子。
4. 服务器按客户端样本比例加权平均各专家因子，得到新全局因子。
5. 最终输出全局因子和客户端私有参数。
