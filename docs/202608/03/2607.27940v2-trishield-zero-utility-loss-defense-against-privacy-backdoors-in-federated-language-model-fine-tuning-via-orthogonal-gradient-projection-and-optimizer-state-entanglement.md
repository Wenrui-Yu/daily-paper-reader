## 摘要
大型语言模型（LLM）的联邦微调使得在不暴露原始数据的情况下进行协作训练成为可能。然而，最近的一种名为NeuroImprint的攻击表明，恶意参数服务器可以将PEFT适配器篡改为隐私后门：通过为每个训练样本分配一个专用的记忆神经元，并确保每个神经元最多更新一次，服务器可以在高语义保真度下分析性地重建59%–79%的客户端训练数据。现有的防御措施——包括本地差分隐私（LDP）和梯度裁剪——要么无法抵御这种攻击，要么导致不可接受的效用退化。我们提出了TriShield，一种三层确定性防御机制，能够完全阻止NeuroImprint式的重建，且零模型效用损失，无需额外的通信轮次。TriShield包括：（1）参数伪影检测器，在本地训练开始前识别分布式模型参数中的记忆神经元特征；（2）有状态虚拟迭代机制，强制Adam/AdamW的动量状态在虚拟步骤间不可逆地纠缠梯度，使NeuroImprint的闭式求逆失效；（3）零效用正交投影算子，通过SVD计算主任务语义子空间，并将所有本地梯度更新投影到该子空间，从物理上消除携带私有记忆的任何梯度成分。我们从理论上证明，在第2层和第3层之后，上传的梯度与任何单个训练样本之间的互信息为零。在GPT-2（117M）和Llama-Guard-3-1B上的实验验证，TriShield在所有测试的攻击变体下将NeuroImprint重建率降至0%，同时保持或提高了训练准确率，且额外GPU计算开销不到5%。

## Abstract
Federated fine-tuning of large language models (LLMs) enables collaborative training without exposing raw data. However, a recent attack, NeuroImprint, demonstrates that a malicious parameter server can corrupt a PEFT adapter into a privacy backdoor: by assigning a dedicated memorization neuron to each training sample and ensuring each neuron updates at most once, the server can analytically reconstruct 59%--79% of client training data with high semantic fidelity. Existing defenses---including local differential privacy (LDP) and gradient clipping---either fail against this attack or impose unacceptable utility degradation. We present \textbf{TriShield}, a three-layer deterministic defense that completely prevents NeuroImprint-style reconstruction with zero model utility loss and no additional communication rounds. TriShield consists of: (1) a Parameter Artifact Detector that identifies memory-neuron signatures in distributed model parameters before local training begins; (2) a Stateful Virtual Iteration} mechanism that forces Adam/AdamW's momentum state to irreversibly entangle gradients across virtual steps, invalidating NeuroImprint's closed-form inversion; and (3) a Zero-Utility Orthogonal Projection operator that projects all local gradient updates onto the main-task semantic subspace computed via SVD, physically eliminating any gradient components that carry private memorization. We prove theoretically that after Layers 2 and 3, the mutual information between the uploaded gradient and any individual training sample is zero. Experiments on GPT-2 (117M) and Llama-Guard-3-1B verify that TriShield reduces NeuroImprint reconstruction rate to 0% across all tested attack variants, while maintaining or improving training accuracy, with less than 5% additional GPU computation overhead.

- **研究背景**：联邦微调（Federated Fine-tuning）使多个客户端无需共享原始数据即可协作训练大语言模型（LLM），通常与参数高效微调（PEFT，如 LoRA）结合使用以降低通信与计算成本。
- **核心威胁**：论文聚焦于一种名为 **NeuroImprint** 的隐私后门攻击。恶意参数服务器可篡改下发的 PEFT 适配器，为每个训练样本预植入一个"记忆神经元"；客户端正常训练时，该神经元被激活并恰好更新一次，服务器随后可从客户端上传的梯度中**闭式解析地重建出训练样本**，重建率高达 59%–79% 且不影响模型效用，因而难以被监控发现。
- **现有防御的失效**：
  - **本地差分隐私（LDP）**：需加大量噪声，实际效用损失 5–20%，不可接受；
  - **梯度裁剪**：攻击者可缩放注入规模绕过低量级检测；
  - **服务端聚合防御（FLAME、FLTrust 等）**：默认服务器诚实，与攻击模型（恶意服务器）直接矛盾；
  - **拜占庭鲁棒聚合（Krum、Trimmed Mean）**：针对的是异常客户端而非异常神经元，无法防御服务器植入的神经元级后门。
- **论文提出的方案**：TriShield——一种**纯客户端侧、三层确定性防御**，可在不修改服务器协议、不牺牲模型效用的前提下，将 NeuroImprint 式攻击的重建率降至 0%。

## 2. 方法论

TriShield 由三个顺序执行的防御层组成，各自针对 NeuroImprint 攻击链中的不同环节：

### 2.1 第 1 层：参数伪影检测器（PAD, Parameter Artifact Detector）

- **作用时机**：本地训练开始之前，客户端扫描服务器下发的适配器参数。
- **检测目标**：NeuroImprint 预植入的记忆神经元具有三个统计学特征：
  1. 行内方差近乎为零（\(<10^{-4}\)，由 LayerNorm 不变性要求所致）；
  2. 多行之间归一化向量高度相关（相关系数 > 0.95）；
  3. 对应 bias 近似为固定常数 \(\beta\)。
- **处理方法**：将检测到的记忆神经元重置为 Kaiming 正态初始化，破坏"槽位–样本"的映射关系。
- **注**：正常初始化下行内方差约为 \(10^{-3}\)–\(10^{-2}\)，误报概率极低（对 \(d_{in}>64\) 低于 \(10^{-6}\)）。

### 2.2 第 2 层：有状态虚拟迭代（SVI, Stateful Virtual Iteration）

- **作用目标**：破坏 NeuroImprint 所依赖的"单次更新、线性可逆"假设。
- **攻击利用的原理**：NeuroImprint 的闭式求逆 \(\hat{x} = \nabla W / \nabla B\) 成立的前提是记忆神经元恰好被更新一次，其梯度与样本嵌入严格成正比。
- **SVI 的操作流程**：
  1. 在真实训练开始前，用公共辅助数据 \(D_{aux}\) 执行 \(K=3\) 次**虚拟优化器步骤**；
  2. 虚拟步骤中**只更新 Adam/AdamW 的动量状态（\(m, v\)），不更新模型参数**；
  3. 每轮虚拟迭代后恢复参数快照，确保适配器权重保持不变；
  4. 真实训练开始时，动量状态已被公共数据梯度"预污染"。
- **防御原理（定理 1）**：真实梯度 \(g_{real}\) 到来后，权重更新变为动量状态 \(m_K, v_K\) 与 \(g_{real}\) 的非线性混合。服务器仅凭最终权重更新无法分离出 \(g_{real}\)，因为 \(m_K, v_K\) 是服务器不可见的客户端私有状态，构成欠定方程组（\(O(d_{in})\) 个未知数、\(O(1)\) 个约束），数学上不可解。

### 2.3 第 3 层：零效用正交投影（ZUOP, Zero-Utility Orthogonal Projection）

- **核心观察**：NeuroImprint 记忆神经元的梯度**天然正交于主任务梯度子空间**——这是其利用 LayerNorm 不变性保持"任务无关"的必然结果。
- **操作流程**：
  1. 用公共辅助数据 \(D_{aux}\) 计算任务梯度矩阵 \(G\)；
  2. 对 \(G\) 做 SVD 分解，取前 \(k\) 个左奇异向量构成主任务子空间 \(U_k\)（默认 rank fraction = 0.80，即捕获 80% 任务梯度方差）；
  3. 将客户端真实梯度 \(\Delta \phi_i\) 投影到 \(U_k\) 上：\(\Delta \phi_i^* = U_k U_k^\top \Delta \phi_i\)，从而物理消除落在正交补空间中的记忆梯度分量。
- **理论保证**：
  - **定理 2（零效用损失）**：若主任务梯度 \(\nabla_\phi L_{task} \in U_{main}\)，则投影不改变任务梯度，即 \(P_{U_{main}} \nabla_\phi L_{task} = \nabla_\phi L_{task}\)；
  - **定理 3（隐私保证）**：对任意满足 \(g_{mem} \perp U_{main}\) 的记忆神经元梯度，投影后 \(P_{U_{main}} g_{mem} = 0\)，重建公式变为 \(0/0\)，重构不可能；
  - **定理 4（信息论界）**：对近似正交（夹角 \(\delta < 5^\circ\)）的记忆梯度，泄露信息量低于样本熵的 1%。

### 2.4 三层协同与理论性质

- **三层互补**：PAD 负责在训练前清除显性后门；SVI 负责破坏闭式求逆的数学前提；ZUOP 提供最终的信息论层面兜底（即使前两层被自适应攻击绕过）。
- **收敛性（定理 5）**：在投影秩足够、辅助数据同分布、梯度有界光滑等条件下，TriShield 下的 FedAvg 与原始 FedAvg 收敛到同一不动点。
- **效率**：无额外通信轮次；GPU 总开销 < 5%；单层开销分别约为 PAD 15ms、SVI <50ms（GPU）、ZUOP <30ms（GPU）。

## 7. 优点

- **问题定位精准**：针对的是联邦学习中最难防御的威胁模型——恶意服务器——而非传统上的恶意客户端，填补了实际安全空白。
- **方法设计具有层次性**：三层防御各司其职，每一层独立有效，可抵御不同变体的自适应攻击，形成纵深防御体系。
- **理论支撑扎实**：提供了互信息归零（定理 3）、泄露信息上界（定理 4）、收敛性保持（定理 5）等数学保证，而非仅依赖经验结果。
- **真正零效用损失**：与 LDP 等"用效用换隐私"的方法相比，ZUOP 的正交投影在理论上保证不损失任务梯度，解决了隐私-效用权衡的核心矛盾。
- **部署友好**：纯客户端侧、无需服务器合作、兼容任意 PEFT 方法、约 100 行代码即可集成到现有 FL 框架。
- **与 GPM 的类比清晰且具有创新性**：将连续学习中"保留旧知识而避开旧任务子空间"的投影机制反向运用于"保留当前任务梯度而消除子空间外分量"，思想巧妙。

## 8. 不足与局限

- **全规模实验缺失**：论文中最重要的性能声明（59–79% 降至 0%、效用损失 ≤0.3%）在 GPT-2/Llama 全规模数据上均为投影估算而非实测。作者也承认这一点，并指出多 GPU 实测留待未来工作。
- **本地验证统计力度不足**：15 条私有样本的 demo 规模难以反映真实训练动态，单样本精度 6.67% 的粒度使任何准确率比较都缺乏统计意义。
- **辅助数据假设**：ZUOP 依赖 32–500 条与私有数据同分布的公共辅助数据。在高度专业化的领域（如医学基因组学、特定法律语料）中，这一假设可能难以满足；辅助数据分布偏移会直接影响投影质量和效用保持。
- **CPU 开销被弱化**：论文摘要强调 GPU 开销 <5%，但 CPU 上总开销高达训练轮次的 72%，对边缘设备部署构成现实障碍，论文仅以"建议使用 GPU 加速"一笔带过。
- **理论的潜在局限**：
  - 定理 2 的前提"任务梯度位于 \(U_{main}\) 中"依赖辅助数据分布与私有数据分布一致，若偏离则投影可能截断真实任务梯度；
  - 隐私保证限于 NeuroImprint 这一攻击类别，对跨神经元纠缠编码、非 LoRA 适配器等其他攻击形式需要扩展分析；
  - 信息论界中 \((m_K, v_K)\) 不传服务器是安全基础，但真实 FL 系统中若客户端状态被恶意软件或其他侧信道泄露，此假设会被打破。
- **公平性存疑点**：实验对比中未包含同等条件下的 FLAME（因服务器不可信场景不适用的原因可理解）、PRECODE 等方法的直接比较；LDP 基线的

LDP 基线的噪声预算设置（ε=1.0 与 8.0）缺乏与 TriShield 隐私保证的定量对比，且其实用性损失结果亦为投影估算；同时缺少与 PRECODE、InstaHide 等近期客户端侧防御的直接比较，使得 TriShield 的相对优势难以在统一框架下量化。

总体而言，TriShield 在针对恶意服务器的 LoRA 后门隐私攻击防御上提供了创新且坚实的理论框架，其三层纵深防御设计、零效用损失的数学保证以及极低的部署开销是显著亮点。然而，全规模实测的缺失、辅助数据假设的局限以及对比实验的不均衡，使其目前在工程实践中的推广仍需更多验证。论文的价值在于开辟了“客户端侧基于子空间投影的隐私防御”这一新方向，并为后续研究提供了可扩展的分析框架。
